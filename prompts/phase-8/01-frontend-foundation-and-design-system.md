# Phase 8 — Frontend Foundation and Design System

## Objective
Build a professional frontend for the portfolio-rebalancing workflow, aligned with the actual backend capabilities.

## Foundation
- Inspect the repository and backend API contracts before implementation.
- Establish the frontend application shell, routing/navigation and reusable layout.
- Use the selected React/Vite frontend stack and existing project conventions.
- Keep API communication in a defined integration layer.
- Provide loading, empty, validation and error states.
- Do not introduce a parallel or duplicate backend contract.

## Design system
- Define reusable color, typography, spacing, radius, elevation and component tokens.
- Support light and dark themes with a consistent interaction model.
- Use accessible contrast, keyboard interaction and clear focus states.
- Keep dashboards information-dense but readable.

## Feature areas
- Dashboard and portfolio overview.
- Portfolio management and holdings.
- Rebalancing workspace.
- Approvals and governance.
- Policy intelligence and grounded explanations.

## UX principle
Use financial terminology accurately. Distinguish actual holdings, proposed trades, blocked trades, simulated post-trade values and approved decisions.
