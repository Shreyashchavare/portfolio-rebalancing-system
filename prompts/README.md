# AI Prompt History

This directory maintains the prompt history used during the development of the Portfolio Rebalancing Recommendation System.

## AI Tools Used

| Tool | Purpose |
|---|---|
| ChatGPT | Technical guidance, architecture decisions, development planning, testing strategy and code review |
| Antigravity | Code generation, implementation assistance and debugging |
| Codex | Additional coding assistance |
| Claude | Documentation assistance |

## Prompt Organization

Prompts are organized phase-wise.

Each phase contains:
- Prompt files submitted to AI tools.
- Tool name and date.
- Objective of the prompt.
- Summary of generated output.
- Human review and modifications.
- Test and verification results.

## Development Principles

1. AI-generated code is reviewed before acceptance.
2. Tests are executed before considering functionality complete.
3. Architecture and technical decisions are reviewed manually.
4. No AI-generated implementation is accepted without understanding it.
5. Prompts and relevant AI assistance are recorded transparently.

## Human Responsibility

The project developer is responsible for architecture decisions, implementation review, testing, debugging, integration, security and final submission.
