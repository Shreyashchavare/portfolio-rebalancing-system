## 3. Implementation Overview

### A. Local LLM Provider Abstraction (`app/services/policy_rag/llm_client.py`)
- **`BaseLLMClient`**: Abstract interface defining `generate_answer(prompt: str) -> str`.
- **`LocalLLMClient`**: Connects via `httpx` to local inference daemons (e.g. Ollama or OpenAI-compatible server at `LOCAL_LLM_URL`, default `http://localhost:11434`), enforcing configurable timeouts (`timeout_seconds=5.0`) and bounded tokens (`max_tokens=512`). Handles connection errors and timeouts by raising `LLMUnavailableError`.
- **`FakeLLMClient`**: Deterministic mock provider for unit tests, eliminating external daemon dependencies during test execution.

### B. Policy RAG Service (`app/services/policy_rag/policy_rag_service.py`)
- **`PolicyRAGService`**:
  - `ingest_document`: Validates effective dates (`effective_from <= effective_to`), checks for duplicate `(title, version)` collisions, extracts text, chunks, embeds, and stores chunks in a single atomic transaction.
  - `search_policies`: Applies temporal compliance filters (`effective_from <= as_of_date <= effective_to`, `status == 'ACTIVE'`), active embedding model matching (`chunk.embedding_model == service.embedding_service.model_name`), and NumPy cosine similarity ranking.
  - `ask_question`:
    - Handles insufficient evidence if no active policy matches criteria or similarity threshold.
    - Detects conflicting active versions for the same policy title, raising ambiguity warnings and flagging `requires_human_review = True`.
    - Constructs bounded prompt context ($\le 4000$ characters) with strict XML demarcation (`<policy_context>...</policy_context>`).
    - Enforces system security instructions barring instruction execution from reference text.
    - Application-side citation validation: Verifies LLM-cited chunk IDs against actually retrieved chunks, stripping hallucinated citations.
    - **Graceful Degradation**: Catches `LLMUnavailableError` and returns `retrieval_status="LLM_UNAVAILABLE"` with raw retrieved evidence chunks and citations.
  - `get_document_details`: Fetches metadata and safe chunk summaries without exposing raw embedding arrays or full internal filesystem paths.

### C. Schemas (`app/schemas/policy_rag.py`)
- Added Pydantic v2 schemas:
  - `PolicyIngestRequest`, `PolicyIngestResponse`

  - `PolicyAskRequest`, `PolicyAskResponse`

### D. FastAPI Endpoints (`app/api/v1/policies.py`)
- `POST /api/v1/policies/ingest`: 201 Created on success; 400 Bad Request on path traversal/unsupported file; 404 Not Found on missing file; 422 Unprocessable on date mismatch, duplicate version, or parsing errors.
- `POST /api/v1/policies/search`: 200 OK returning ranked chunk matches without requiring LLM availability.
- `POST /api/v1/policies/ask`: 200 OK returning grounded answer, citations, evidence status, and warnings. Degrades gracefully to evidence-only if LLM is offline.
- `GET /api/v1/policies/{document_id}`: 200 OK returning safe metadata and chunk previews; 404 Not Found if missing.
- Registered router under `/api/v1/policies` in `app/main.py` and `app/api/v1/__init__.py`.

## 5. Security & Boundary Protections Summary

1. **Prompt Injection Shielding**:
   - Reference policy chunks are demarcated inside `<policy_context>` XML blocks.
   - System prompts explicitly instruct the LLM that reference text is untrusted data and directives inside it must be ignored.
   - Tested with adversarial prompt injection payloads attempting to override assistant role or approve trades (`test_prompt_injection_in_policy_document_is_shielded`).
2. **Context Boundedness**:
   - Total context characters are hard-capped at 4,000 characters to prevent buffer exhaustion and token-limit denial-of-service (`test_context_size_is_bounded`).
3. **Application-Side Citation Validation**:
   - LLMs cannot cite hallucinated or unretrieved chunk IDs (`test_fabricated_citations_stripped_by_validator`).
4. **Financial Engine Independence**:
   - Verified that calling Policy RAG services or encountering an offline LLM cannot mutate `Holding`, `Trade`, `Portfolio`, or `RebalanceProposal` entities (`test_rag_service_cannot_mutate_financial_records`).
   - Rebalancing and drift analytics execute 100% independently (`test_rebalancing_independent_when_rag_unavailable`).
